# STATS BALANCE PUTTING TRACE（試作版）

パッティング動画から、**実際に写っているゴルフボールの画像**を切り出し、
転がった位置に何個も並べた「残像画像（PNG）」を作る、iPhone Safari 向けの Web アプリです。

- 動画は **端末の中だけ** で処理します（外部サーバーへの送信はありません）。
- 画面・ボタン・説明はすべて日本語です。
- グリーン傾斜計アプリ（green-slope-meter）とは**完全に独立した**アプリです。

**公開URL（iPhone の Safari で開く）**：https://okiko1110-tech.github.io/putting-trace-app/

## 使い方（3つの画面）

1. **動画選択**：「動画を撮影」または「動画を選択」
2. **動画解析**（手順1〜5）
   1. ボールが転がり始める時点を「開始」にする
   2. ボールが止まった時点を「終了」にする
   3. 開始時点の画面でボールをタップ（自動で円が合います。矢印で微調整可）
   4. 残像の間隔（0.05 / 0.1〔標準〕 / 0.2 秒）を選んで「追跡を開始」
   5. 各時刻の位置を確認・修正
      - 緑＝自動認識、青＝手動指定、黄＝要確認、赤＝未検出、灰＝除外
      - 時刻ボタンを押して画面をタップすると、その時刻の位置を手動で指定できます
      - 「ここから再追跡」で、手動指定した位置から先を追跡し直せます
3. **残像画像**：「写真に保存・共有」→「画像を保存」で写真アプリへ保存

## 仕組み（かんたんな説明）

| 処理 | 方法 |
| --- | --- |
| フレーム取り出し | `<video>` を指定時刻にシークし、Canvas に描画 |
| フレームレート | 読み込み時に少し再生し、実際のフレーム時刻（requestVideoFrameCallback）から推定 |
| 残像の時刻 | 開始＋間隔×n に最も近い **実際のコマ** を使用（撮影時刻に基づく）。コマの都合で指定どおりにならない場合は画面に表示 |
| ボール検出 | 「白さ＝明るさ−色の濃さ」が周囲より高いかたまりを探す。大きさ・予測位置からの距離・形・開始フレームとの違い（静止した別のボールを除外）で採点 |
| 追跡 | 約1/30秒ごとに、直前の速度から次の位置を予測して周辺を探索 |
| 合成 | 各時刻のフレームからボール周辺を円形に切り抜き、**背景と違う部分（ボール）だけ** を残して背景フレームに重ねる |

自信の低い結果は「要確認」、見つからない場合は「未検出」とし、勝手に正しい位置として画像に入れません。

## 開発者向け

```bash
npm install
npm run dev      # 開発サーバー（同じ Wi-Fi の iPhone から http://<PCのIP>:5173 で開ける）
npm test         # ボール検出・時刻計算の単体テスト
npm run build    # 公開用ファイルを dist/ に作成
npm run e2e      # 合成動画を使ったブラウザ操作テスト（ffmpeg・Python・Playwright が必要）
```

- `src/lib/video.ts` … 動画読み込み・シーク・フレームレート推定
- `src/lib/detect.ts` … ボール検出（画像処理）
- `src/lib/tracker.ts` … 残像の時刻決定と追跡
- `src/lib/composite.ts` … 残像画像の合成・PNG 出力
- `src/screens/*` … 3つの画面

GitHub Pages への公開は `.github/workflows/deploy.yml` で自動化しています。
main ブランチに変更が入ると、テスト → ビルド → 公開 が自動で行われます
（初回のみ、リポジトリの Settings → Pages → Source を「GitHub Actions」に設定）。
